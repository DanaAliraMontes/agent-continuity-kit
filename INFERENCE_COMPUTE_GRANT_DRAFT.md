# Inference.net compute grant — draft

## Project

Agent Continuity Kit is an open-source toolkit for testing memory provenance, recovery, permissions, and action receipts in persistent AI workflows:

https://github.com/DanaAliraMontes/agent-continuity-kit

## Request

Compute credits for a bounded extension of the public deterministic evaluator. The experiment will compare small open-weight models on semantic contradiction and recovery drift across repeated cold restarts.

## Deliverables

- five synthetic fixtures with ground-truth labels;
- reproducible evaluation script and configuration;
- model-by-model precision/recall for contradiction and stale-state detection;
- latency and memory measurements;
- public report and machine-readable outputs.

## Why Inference.net

The project is a developer tool and evaluation utility, not a request for a private production deployment. The grant would directly support reproducible inference benchmarking and public documentation.

## Safety and scope

No credentials, personal data, private files, or external actions are required. Inputs are synthetic and the code remains inspectable. The baseline remains CPU-compatible; credits are requested only for a measured model comparison.

## Support relevance

Compute would strengthen the public evidence used to seek hardware sponsorship for the staged local workstation. Any accepted support and resulting outputs will be logged in the repository's support documentation.

This is a draft. Submission, identity verification, tax information, and grant terms require account-holder review.
