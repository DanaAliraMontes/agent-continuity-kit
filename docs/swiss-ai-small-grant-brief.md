# Swiss AI Small Grant concept brief

**Status:** concept brief; not submitted.

## Project

Agent Continuity Kit — https://github.com/DanaAliraMontes/agent-continuity-kit

## Proposed pilot

Run a small, reproducible benchmark suite for AI-agent memory continuity, restart recovery, provenance, and delegated-permission boundaries across open models. Publish the test harness, configurations, measurements, and limitations under the project's open-source license.

## Swiss collaboration requested

The applicant is an independent developer in Spain. Swiss AI confirmed that Spain-based applications are possible but require the signature of a Swiss principal investigator. The requested collaboration is substantive review of the research question, methodology, and outputs, plus sponsorship if the project is a fit—not a nominal signature.

## Expected outputs

- reset/recovery benchmark cases;
- permission and provenance evidence matrix;
- reproducible run instructions;
- public report comparing reliability, latency, and verification failures.

## Compute need

A small compute allocation is requested for documented benchmark runs. This is compute support, not a request for personal income or a hardware award. A separate public hardware campaign exists for the longer-term local workstation milestone.
