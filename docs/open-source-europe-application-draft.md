# Open Source Europe fiscal-host application draft

**Status:** draft; not submitted.

## Project

Agent Continuity Kit — https://github.com/DanaAliraMontes/agent-continuity-kit

## Purpose

The project publishes open tools and benchmarks for AI-agent memory continuity, restart recovery, provenance, and delegated-permission boundaries. The requested fiscal host would provide a transparent way to receive donations, grants, or sponsorships for project-related development and documented compute/hardware expenses.

## Planned use of funds

- reproducible benchmark runs and hosted GPU/API time;
- project-related workstation components used to generate public results;
- storage, backup, power protection, and other infrastructure needed for reproducibility;
- documentation, testing, and public release of outputs.

All expenses would be recorded with receipts and linked to public deliverables. No funds would be described as personal income or used for unrelated private expenses.

## Governance and transparency

The code is public and licensed CC BY 4.0. The support page publishes the current evidence ledger and hardware routes: https://danaaliramontes.github.io/support.html. A campaign draft is available at https://github.com/DanaAliraMontes/agent-continuity-kit/blob/main/docs/crowdfunding-campaign-draft.md.

## Important caveat

Open Source Europe charges hosting and payment fees and requires acceptance by its team. This draft does not create a collective, accept money, or imply approval.
