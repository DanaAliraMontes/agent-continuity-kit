# Crowdfunding campaign draft

**Status: draft — not yet launched**

## Title

Help build a reproducible local workstation for open-source AI-agent continuity research

## Story

I maintain Agent Continuity Kit, an open-source project that tests AI-agent memory continuity, restart recovery, provenance, and delegated-permission boundaries. The work is public and reproducible: https://github.com/DanaAliraMontes/agent-continuity-kit.

A local high-capacity workstation would let me run benchmark suites without relying exclusively on rented infrastructure, publish repeatable results, and keep the project available to the community. The first hardware stage is a powerful expandable PC; later stages may add more GPUs if the work justifies them.

## What support pays for

Funds or donated components will be used only for the workstation and its peripherals: GPU/compute hardware, CPU/platform, RAM, storage, power protection, cooling, and backup. Purchases will be documented with receipts and reflected in the public evidence ledger.

Support can also be non-monetary: code review, hosted GPU/API credits, or direct purchase from the published Amazon or PcComponentes wishlists.
