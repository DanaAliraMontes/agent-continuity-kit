# Since AI Hackathon 2026 — submission brief

## Working title

**Continuity Bench for Reliable AI Workflows**

## Project

An open-source tool that tests whether an AI workflow can recover its objective, provenance, permissions, and action receipts after interruption. It provides a deterministic baseline plus an optional model-assisted comparison.

## Prototype for the 72-hour event

- a working recovery-check agent;
- synthetic fixtures for complete and failed recovery;
- a human approval gate when evidence is missing;
- a clear dashboard/report showing what survived and what did not;
- public source code, setup instructions, and a short demonstration.

## Commercial and social value

The same test can help small teams decide whether an automation is ready for real users. It turns vague “agent reliability” into observable checks and a fix-first report.

## Existing starting point

The Agent Continuity Kit already contains a deterministic evaluator, recovery templates, permission ledger, reset drill, risk matrix, and public sample output. Pre-existing material will be disclosed as required by the event rules; work produced during the official event will be identified separately.

## Support/compute use

Event infrastructure and any prize would support the staged local workstation and further public evaluation of open-weight models. No private production data or credentials are needed.
