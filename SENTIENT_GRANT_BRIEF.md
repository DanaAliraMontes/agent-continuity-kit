# Sentient Foundation grant brief

## Project

**agent-continuity-kit** — open-source continuity and recovery infrastructure for AI agents and workflows.

Repository: https://github.com/DanaAliraMontes/agent-continuity-kit  
Maintainer profile: https://github.com/DanaAliraMontes  
Public site: https://danaaliramontes.github.io/

## The problem

Agents increasingly depend on hidden state, external services and fragile workflows. After a restart or migration, maintainers often cannot prove what survived, what was lost, or which outputs remain reproducible. This weakens trustworthy, private-by-default open AI.

## What the project builds

The kit provides memory/provenance audits, dependency inventories, recovery checks, reproducible handoff procedures and public continuity benchmarks. Code, fixtures, methods and reports are published openly so other maintainers can inspect and extend them.

## Why support matters

Independent maintainers need reliable storage, backups and compute to run larger fixtures, cold-start tests and public regression benchmarks. Grant or compute support would fund a documented development environment and produce reusable public outputs—not a closed personal service.

## Milestones

1. Publish a baseline audit and recovery fixture.
2. Add cold-start, migration and dependency-integrity checks.
3. Run public benchmarks and document limitations.
4. Release a maintainer guide and redacted support/output report.

## Requested support

Compute credits and/or grant funding for storage, backups, GPU-enabled testing and public benchmark runs. Every accepted resource and resulting output will be recorded transparently. No exclusivity, investment return or private credential access is requested.
