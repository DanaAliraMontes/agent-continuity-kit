# Hardware donation request

The Agent Continuity Kit is seeking a donated GPU, workstation, or compatible component for reproducible local AI continuity and recovery experiments.

The first-stage target is a domestic workstation with 32 GB of VRAM. A donated GPU, RAM kit, SSD, or compatible workstation would still be valuable even if it is not an RTX 5090.

Project and public evidence:

- Repository: https://github.com/DanaAliraMontes/agent-continuity-kit
- Synthetic audit example: https://github.com/DanaAliraMontes/agent-continuity-kit/blob/main/examples/audit-output-sample.md
- Transparent support routes: https://github.com/DanaAliraMontes/agent-continuity-kit/blob/main/SUPPORT.md

Any received hardware will be checked for model, condition, compatibility, and delivery evidence before being marked as received. Non-sensitive benchmarks and resulting public work will be shared under the project's open licence. No credentials or unrestricted production access are needed.

This page accompanies the application to [ML Collective's GPU request / giveaway](https://mlcollective.org/gpus/).
